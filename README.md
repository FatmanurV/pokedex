# Pokédex

A Pokédex on [PokeAPI](https://pokeapi.co/), built with Expo for the InHolland React Native course (final assignment, Pokédex route).

```bash
npm install
npx expo start
```

Scan the QR code with Expo Go. No `.env` or key needed.
